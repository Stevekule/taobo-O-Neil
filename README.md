# taobo-O'Neil · 陶博士欧奈尔体系全流程 Skill

> 这是 **WorkBuddy**（AI 智能体工作台）的一个 *skill*（智能体技能），不是独立运行的 Python 程序。
> 它把「选股 → 仓位管理 → 回测验证」三阶段投资体系封装成可复用的规则与方法论文档。

## 这是什么

本 skill 整合了「陶博士 / 欧奈尔（William O'Neil）」流派的量价选股 + 仓位管理 + 历史回测验证流程，形成一套可机械执行的决策框架：

- **① 选股**：基于 RPS（相对强度）多周期共振、基底形态、基本面质量门（盈利 + ROE）等条件，筛出强势且基本面达标的标的，并维护「重点观察池」。
- **② 仓位管理**：买入后的建仓 / 加仓 / 减仓 / 清仓规则（动态净值三分建仓、中期信号门控、离场引擎、淘弱留强），以及 ETF 与黄金标的的差异化止盈口径。
- **③ 回测验证**：任何规则变更都先用 2011–2026 全市场数据做完整交叉网格回测，再定稿，附带赔率 / 胜率 / 年化等强制统计指标。

## 安装（WorkBuddy）

把整个 `taobo-O'Neil` 文件夹放到 WorkBuddy 的 skills 目录下即可，**文件夹名即 skill 名**：

- 用户级：`~/.workbuddy/skills/taobo-O'Neil/`（对所有项目生效，推荐）
- 项目级：`<你的项目>/.workbuddy/skills/taobo-O'Neil/`

放入后，在对话里提到「选股 / 仓位管理 / 回测 / RPS」等触发词，WorkBuddy 会自动加载本 skill。

## 数据依赖

- 选股 / RPS / 财务数据来自**本地通达信**管线（`vipdoc` 日 K 线 + 本地 screener 产物）。
- 回测使用本地历史行情，不依赖任何付费接口。
- 本仓库**不包含**任何个人持仓或真实账户数据，可直接公开。
